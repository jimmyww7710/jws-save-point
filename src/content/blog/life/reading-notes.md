這本書最打動我的一句話是：**「你不會提升到目標的水準，而是會降到系統的水準。」**

## 四個行為改變法則

| 法則 | 建立好習慣 | 戒除壞習慣 |
| --- | --- | --- |
| 提示 | 讓它顯而易見 | 讓它隱而不現 |
| 渴望 | 讓它有吸引力 | 讓它缺乏吸引力 |
| 回應 | 讓它簡便易行 | 讓它困難無比 |
| 獎賞 | 讓它令人滿足 | 讓它令人不滿 |

## 我的實踐

1. 把寫文章的門檻降到最低：在 VS Code 開一個 Markdown 檔就能開始寫。
2. 每天至少寫 **兩分鐘** 的筆記，不要求完整。
3. 每次 `git push` 就是一次小小的獎賞，看到網站更新很有成就感。

> 習慣是自我提升的複利。
